Custom CNNs vs Pretrained Models

A visual, per-sample comparison across all four HandsFree inputs — no bar charts, no pie charts, no line graphs. Every model is scored on the same held-out data with the same metrics; each figure is drawn from real per-sample predictions.

How to read the comparison honestly. Gaze and head pose are true neural-net-vs-neural-net comparisons on matched samples. Voice compares the custom CNN against pretrained Vosk (summary metrics only). Blink’s alternative is a classical maths rule, not a neural net, so it is shown as a deep audit of the custom model.
Work in progress. I am still refining the hyperparameter tuning for the gaze and head-pose custom models to push their accuracy further, with the goal of making them as competitive with the pretrained models as the custom blink and voice models already are.

Gaze · custom CNN vs pretrained MPIIGaze ResNet

Matched per-sample on the custom model's HELD-OUT participants (p05, p07) only — the full 15-participant set contains nine of its own training people and flatters it by ~1.9°. Each model gets its own preprocessing. The pretrained baseline was trained on MPIIGaze and likely saw these participants, so the comparison is conservative towards ours.
